# パソコン管理台帳
Version 2.0では、登録後のデータ修正および検索機能を実装し、運用段階で発生するデータメンテナンス作業へ対応しました。
## 概要
本プロジェクトは、実際の業務で適用している Excel VBA ベースのパソコン管理台帳をもとに業務フローを分析し、Excel＋Python＋PySide6 を利用して、シンプルで運用しやすい業務アプリケーションとして再設計することを目的としたプロジェクトです。
目的は、
- 登録作業の効率化
- 検索作業の効率化
- 修正ミスの削減
- データ管理品質の向上
- 帳票出力の効率化

です。
## 開発のきっかけ
Excel台帳でパソコン管理を行っていた中、
- 重複発番
- 検索性の悪さ
- 入力ミス

の発生を補うため、Excel VBAを駆使したが手作業で行う部分が多数あるため、

Pythonによる管理ツールを作成してみようと思いました。
## このツールで解決すること
- パソコン発番の自動化
- ユーザー選択の簡略化
- マスタ管理の一元化
- Excel台帳への自動登録
- 検索・修正作業の効率化
## 開発について
本プロジェクトは、
**Microsoft Copilotを開発パートナー**として活用しながら、
業務フローの整理、仕様検討、画面設計および実装を進めています。

一人では頭の中の構想で終わっていたかもしれないアイデアを、Copilotとの対話を通じて設計書や仕様書として形にし、業務システムとして実現することに挑戦しています。
